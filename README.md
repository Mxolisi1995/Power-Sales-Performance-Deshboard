# Sales Performance Dashboard

## Overview

This project presents a Sales Performance Dashboard developed in Power BI to analyze sales, profit, product performance, discount bands, and country performance.

## Business Problem

Businesses need a clear way to monitor sales performance and identify opportunities for growth. This dashboard provides an interactive view of key performance indicators to support data-driven decision-making.

## Tools Used

* Power BI
* Excel
* Data Visualization
* Business Intelligence

## Key Insights

* Medium Profit Class generated the highest sales.
* Paseo was the top-performing product.
* High Discount Band contributed the largest share of sales.
* Canada, France, and the United States showed strong sales performance.
* Positive profits were recorded across all countries.
